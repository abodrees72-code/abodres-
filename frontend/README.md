# Auction Live App - Frontend

This directory contains the Flutter frontend for the Auction Live App. It delivers a feature-rich and user-friendly interface for bidding and auction management.

## Features
- Support for both Arabic and English languages.
- Interactive and dynamic user experience.
- Live updates for bids via WebSocket.
- Multi-platform support (iOS, Android).

## Getting Started
1. Install [Flutter](https://docs.flutter.dev/get-started/install) and set up your environment.
2. Run `flutter pub get` to fetch dependencies.
3. Use `flutter run` to launch the app.

## Folder Structure
- `lib/`: Main codebase for the Flutter app.
- `assets/`: Contains images, fonts, and localization files.
- `screens/`: Defines the UI screens (e.g., HomeScreen, AuctionDetailsScreen).
- `services/`: Handles API calls and WebSocket connections.
